# YT Daily Scan

Скрипт раз в сутки (GitHub Actions) просматривает YouTube-каналы, берёт видео за **текущий день**,
скачивает транскрипт, через LLM определяет, есть ли информация о цене/ценовом уровне/зоне
по инструменту, и присылает в личку саммари:
`Инструмент / Тикер / Цена / Уровень / Действие (покупка-продажа) / Суть`.

Проживает прямо на GitHub, отдельный хостинг не нужен. Нужен только Node.js (ставят Actions).

## Каналы

Два способа:
1. В `yt-follower.js` в массив `DEFAULT_CHANNELS` впиши каналы: `UC...` (прямой ID),
   `@handle` или `youtube.com/@handle`.
2. Или задать переменную окружения `CHANNELS` (список через запятую) в Actions.

## Настройка (один раз)

В GitHub-репозитории: **Settings → Secrets and variables → Actions** добавь:

| Secret | Значение |
|---|---|
| `BOT_TOKEN` | токен бота из @BotFather |
| `CHAT_ID` | твой id (или канал для пересылки) |
| `LLM_API_KEY` | ключ OpenAI-совместимого API |
| `LLM_BASE_URL` | можно не задавать, по умолчанию `https://api.openai.com/v1` |
| `LLM_MODEL` | можно не задавать, по умолчанию `gpt-4o-mini` |

Переменная `CHANNELS` (не секрет) — если список каналов держишь вне кода.

Секреты `BOT_TOKEN` и `CHAT_ID` уже зашиты в код как значения по умолчанию,
так что можно обойтись только `LLM_API_KEY`.

## Расписание

В `.github/workflows/daily.yml`: `cron: '30 6 * * *'` — каждый день в 6:30 UTC (9:30 МСК).
Измени при желании. Запустить вручную можно кнопкой **Run workflow** на вкладке Actions.

## Как работает фильтр «за сегодня»

Видео считается «сегодняшним» по дате публикации в часовом поясе МСК (UTC+3),
чтобы запуск в 9:30 МСК захватывал все свежие утренние выпуски. Уже отправленные видео
запоминаются в `seen-videos.json`, который workflow коммитит обратно в репозиторий —
бесплатных секретов и приложений не нужно.

## Тестовый режим

Сейчас 00:00–08:00 МСК свежих видео может не быть — чтобы проверить прямо сейчас,
добавь переменную окружения (НЕ секрет, как `CHANNELS`):
1. Settings → Secrets and variables → Actions → **Variables** → **New repository variable**
2. **Name:** `TEST_LATEST`, **Value:** `true`
3. Actions → daily-scan → Run workflow

Бот возьмёт последнее видео каждого канала (любой даты) и пришлёт саммари.
После проверки переменную `TEST_LATEST` удали.

Точечная проверка одного видео: переменная `TEST_VIDEO_ID` = ID ролика (например `dQw4w9WgXcQ`).

## Запуск локально

```powershell
npm install
$env:LLM_API_KEY="ваш_ключ"
node yt-follower.js
```

Локально из РФ/сетей без доступа к YouTube и Telegram скрипт не отработает — это ок,
он задуман для GitHub Actions (там доступ свободный).
