# TG Posts Follower

Бот следит за публичными Telegram-каналами: отсеивает рекламу и посты без чисел,
через LLM проверяет, есть ли в посте цена/ценовой уровень/зона по инструменту,
и присылает в личку саммари вида «Инструмент / Тикер / Цена / Уровень / Действие».

## Запуск локально (для проверки)

Нужен Node.js 18+ (npm-зависимостей нет, ставить ничего не надо).

```powershell
$env:LLM_API_KEY="ваш_ключ"     # обязательно, без него LLM не работает
node tg-follower.js
```

Первый запуск только фиксирует «базовую точку» (ID последних постов) и ничего не шлёт —
чтобы не заспамить историей канала. Дальше каждые 4 часа проверяет новые посты.

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | токен из проекта | токен бота из @BotFather |
| `CHAT_ID` | id из проекта | твой id (или id канала для пересылки) |
| `LLM_API_KEY` | — (обязательно) | ключ OpenAI-совместимого API |
| `LLM_BASE_URL` | `https://api.openai.com/v1` | базовый URL API |
| `LLM_MODEL` | `gpt-4o-mini` | модель |
| `CHANNELS` | список из проекта | каналы через запятую |
| `CHECK_INTERVAL_MIN` | `240` | интервал проверки, минут |
| `AD_WORDS` | список по умолчанию | слова-маркеры рекламы через запятую |
| `BEFORE_ID` | пусто | состояние (`канал:ID,канал:ID`) — см. ниже |

## Деплой на Railway

1. Загрузи папку `tgparc` в GitHub-репозиторий (нужны `package.json`, `tg-follower.js`, `.gitignore`).
2. На railway.app → **New Project → Deploy from GitHub repo**.
3. Railway сам запустит `npm start` (Node 18+).
4. Добавь переменные в **Variables**: `LLM_API_KEY` (обязательно), при желании `BOT_TOKEN`, `CHAT_ID`, `CHANNELS`, `CHECK_INTERVAL_MIN`.
5. Перед первым запуском напиши боту `/start` (иначе бот не сможет написать первым в личку).

## Про состояние (BEFORE_ID)

Диск на Railway эфемерный — при редеплое состояние теряется. В журнале бот печатает готовую
строчку `BEFORE_ID=канал:ID,...`. При перезапуске сервиса вставь её в переменную `BEFORE_ID`,
чтобы бот не прислал повторно уже обработанные посты.
